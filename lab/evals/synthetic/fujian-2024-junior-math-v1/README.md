# 2024 福建中考数学真实流程仿真数据集

本数据集用于验证 EduGrade 从考试建档、答题卡切题、OCR 置信度分流、客观题规则判分到主观题智能体辅助和教师复核的完整生产流程。它使用真实公开试卷和参考答案，但考生、字迹、条码、扫描噪声及作答内容均为匿名模拟。

## 数据边界

- `synthetic=true`、`simulation_only=true`、`training_allowed=false`。
- 不包含真实学生姓名、准考证号、学校、班级或其他身份信息。
- 真实手写答题卡只用于观察版式、手写与扫描难度，没有复制到本数据集。公开样例含身份字段且与本试卷不匹配，因此即使是非商业验证也不导入。
- 本数据集用于流程验证和人工评估，不代表真实学校、真实考生或官方评分结果。

## 真实来源

- 试卷与参考答案：[泉州市教育局——2024 年福建省初中学业水平考试试题、参考答案](https://jyj.quanzhou.gov.cn/wsbs/bgxz/202406/t20240621_3049176.htm)。页面注明来源为福建省教育考试院；本地仅截取数学试题和数学参考答案。
- 答题卡规则参考：[北京教育考试院——答题卡作答注意事项](https://www.bjeea.cn/html/ksb/zhongyaoxinwen/2024/0716/85579.html)，用于约束 2B 铅笔选择题、黑色签字笔作答、条码区和答题边界。
- 真实手写版式参考：[CSDN 公开答题卡样例](https://blog.csdn.net/QQ_1309399183/article/details/149368962)，页面标注 CC BY-SA 4.0；由于含身份字段且不是同一试卷，未导入产品。

具体抓取日期、校验值和用途见 `sources.json`。

## 内容

- 4 名匿名模拟考生，覆盖清晰正确、清晰但错误、涂改/多选/空白/低置信度、倾斜压缩与混合置信度四类情况。
- 每名考生 2 页，共 8 张答题卡图像及 4 份合并 PDF。
- 数学第 1–19 题：10 道选择题、6 道填空题、3 道解答题，总分 88 分。
- 19 个标准题目、76 个答题区域、预期文本、置信度和人工复核路由。
- 官方数学试题、官方数学参考答案、匿名空白答题卡模板。

主要文件：

| 路径 | 用途 |
| --- | --- |
| `manifest.json` | 数据集版本、治理标志和自动化阈值 |
| `questions.json` | 题目、答案、分值和判分策略 |
| `candidates.json` | 匿名考生与作答场景 |

| `import-result.json` | 导入本地产品后的考试 ID、资产 ID 与处理计数 |

## 已导入的真实流程

当前本地产品中的考试为 `2024福建中考数学真实流程仿真（Q1-Q19）`，考试 ID 为 `8d4c089f-c88b-40ae-ac77-a14c89c7c7f0`，阅卷教师为 `test_grader`。

导入结果：

- 4 份答卷、8 页、76 个答题片段；
- 4 个双页 OCR 任务及 35 条模拟转写；
- 59 个高置信度客观题成绩由确定性规则自动确认；
- 17 个低置信度或主观题任务分配给阅卷教师；
- 第 17 题已由本地、非 mock 的 Qwen3-4B 智能体生成 1 条建议，建议记录 ID 为 `30bdd991-aa8f-43cd-a12f-747b449d590e`；
- 该建议识别 4 个采分点并给出 8/8，但模型置信度未校准为 0，带有 `schema_repaired`、`score_needs_review` 和 `human_review_required` 风险标记，始终需要教师确认，不会自动发布成绩。

`import-result.json` 是产品侧事实记录；如重新导入或补充智能体建议，以该文件的最新内容为准。

## 自动化结论与限制

能够真实工作的部分：

- 高置信度选择题和填空题可通过版本化确定性规则自动判分并写入确认成绩；
- 低置信度、空白、涂改、多选和所有主观题会进入教师复核队列；
- 主观题可调用本地、非 mock、受治理的 Qwen 模型生成建议，但最终责任仍由教师承担。
- 本地 CPU 推理需要允许完整结构化输出；本数据集已验证的运行预算为单次 360 秒、最多 512 个输出 token，并保留一次无效输出修复机会。

尚未由本数据集证明的部分：

- 35 条 OCR 文本由 `simulation-importer` 按数据集标注真值写入，用于验证多页任务编排和置信度分流，不是 PaddleOCR 在真实手写答题卡上的准确率结果；
- 产品当前缺少稳定的“OCR 文本块自动归属到题段”闭环，因此还不能宣称多份真实手写答题卡已实现无人值守自动阅卷；
- 模板锁定结果使用 `width/height`，切题解析器读取 `w/h`。导入器为本数据集补充兼容别名，但主产品仍应统一坐标契约。

## 重新导入

在 API 和依赖服务已启动后，从 `services/api-gateway` 运行：

```powershell
$env:EDUGRADE_IMPORT_ADMIN_PASSWORD = '<本地管理员密码>'
go run ./tools/import-fujian-2024-math-simulation `
  -dataset 'D:\project\yuejuan\lab\evals\synthetic\fujian-2024-junior-math-v1' `
  -result 'D:\project\yuejuan\lab\evals\synthetic\fujian-2024-junior-math-v1\import-result.json'
```

只为现有考试补充 3 道主观题智能体建议时，加上 `-ai-only -ai-limit 3`。管理员密码只通过环境变量提供，不应写入数据集或提交到版本库。
