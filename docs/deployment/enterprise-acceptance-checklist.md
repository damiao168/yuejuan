# EduGrade Enterprise 企业级验收清单

本文档用于学校、考试机构、教培机构或企业培训部门对 EduGrade Enterprise 进行交付验收。验收过程必须基于真实部署环境、真实权限配置和合成测试数据完成；不得用未标记的 mock、placeholder 或口头说明代替可复验的证据。

## 证据要求

- 每个验收项必须保留截图、接口响应、日志片段、导出文件、测试报告或操作录像之一。
- 涉及学生姓名、答卷原文、成绩、手机号、证件号等敏感信息的证据必须脱敏。
- mock、placeholder、stub、not implemented 能力只能作为“功能边界已声明”的证据，不能作为正式上线能力通过依据。
- 任何上线阻断项未关闭时，验收结论不得为“通过”。
- 正式上线前还必须对照 `docs/deployment/production-readiness-roadmap.md` 关闭 P0 阻断项。
