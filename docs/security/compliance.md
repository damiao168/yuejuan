# 安全与合规设计

## 默认约束

- 学生数据不出校，外部模型默认关闭。
- 答卷图片、成绩、身份字段分级保护。
- AI 输入先脱敏，学生答案不默认用于模型训练。
- 所有导出、改分、发布、权限变更必须留痕。
- 审计日志不可关闭，并使用哈希链防篡改。
- 本地 EXE 缓存加密，设备可远程吊销。

## 权限模型

- RBAC：角色权限。
- ABAC：基于学校、年级、学科、考试、题目的属性规则。
- Data Scope：租户、学校、年级、班级、题目范围。
- Field Permission：姓名、学号、成绩、备注字段权限。
- Action Permission：导出、发布、批量改分、审批等操作权限。

## 重点测试

- 越权访问。
- 租户逃逸。
- 文件路径穿越。
- 恶意 PDF / OCR 文件攻击。
- Prompt 注入。
- 导出泄露。
- 会话劫持。
- 本地缓存泄露。
- 审计日志篡改。
