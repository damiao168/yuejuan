# Security Principles

## 当前阶段

本文件属于项目骨架 Story，只定义安全原则。完整安全实现会在后续认证、权限、文件、审计和安全加固 Story 中完成。

## 默认安全立场

- 租户隔离是所有业务查询的默认前提。
- 学生姓名、学号、答卷、成绩、申诉内容属于敏感数据。
- 阅卷员默认只看匿名码，不看学生身份。
- AI 输入默认先脱敏，不默认用于模型训练。
- 所有关键操作必须可审计、可追溯、可回放。
- 文件不得直接暴露对象存储路径。

## 必须审计的操作

- 登录、登出、失败登录。
- 创建、修改、归档考试。
- 上传、下载、删除文件。
- 修改题目、标准答案、Rubric。
- 提交 AI 阅卷结果、人工分、仲裁分。
- 改分、成绩确认、成绩发布、成绩导出。
- 申诉受理、驳回、补充、改分。
- 权限、角色、数据范围变更。

## 禁止事项

- 明文保存密码。
- 通过普通日志输出学生答案全文或成绩明细。
- 使用前端权限隐藏替代服务端鉴权。
- 在未标注情况下返回 mock OCR 或 mock AI 结果。
- 允许 AI 输出直接覆盖最终成绩。
- 允许普通接口删除或修改审计日志。
