# STORY-063 计划评审（2026-08-01）

## 评审结论

批准以“单片段建议生成幂等性”作为首个实现切片，暂不进入批量 Worker 和外部 API 接入。

## 依据现状

- `internal/subjective` 已有同步 Handler、受治理的本地 Grading Agent HTTP 适配器、Rubric/答案版本校验和人工复核策略。
- Worker Runtime 已具备租约、心跳、重试和死信原语，但尚无主观题评分的领域源记录与结果回调。
- `ai_grade` 已有 `adapter_request_id` 的唯一约束，当前随机 request ID 仍不足以保证业务重试幂等。
- 阅卷工作台已经展示 AI 建议和证据，教师是唯一确认分数的角色。

## 计划边界检查

本切片不引入新的模型能力、不绕过模型治理、不改变最终成绩语义；只补齐可重试调用所需的请求身份、严格输入和持久化幂等。批次、Worker、进度 UI 和外部厂商适配留到后续独立切片。

## 风险与控制

- 模型输出非确定：同一请求身份已有不同事实时返回 409 冲突，交由人工处理。
- 答案或 Rubric 更新：版本参与请求身份，旧建议不会覆盖新版本。
- 并发写入：内存存储显式去重，PostgreSQL 依赖唯一约束并在冲突后读取既有事实。

## 批准条件

实现必须包含未知字段拒绝、幂等键校验、重复调用测试、冲突测试和现有主观题回归；完成后另行提交实现审阅记录。
