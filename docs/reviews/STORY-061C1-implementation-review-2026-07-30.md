# STORY-061C1 离线模型评测证据实现复审（2026-07-30）

## 结论

通过。已建立租户隔离、不可变且可显式失效的离线模型评测证据后台。该实现不调用任何外部 API，不保存冻结集内容，不 promotion，不改变路由或最终成绩。

## 实现范围

- 新增评测批次和候选记录，快照供应商、部署、模型、Prompt 与 Rubric 版本。
- 保存教师复核、接受、严重错误、证据有效、重复比较、稳定结果、P95 时延和总成本原始计数。
- 服务端派生教师接受率、严重错误率、证据有效率、稳定性和平均成本，避免客户端提交百分比。
- `protocol_fixture` 禁止教师接受计数和授权引用；`authorized_frozen_set` 必须有授权引用且每个样本完成教师复核。
- 完成批次至少需要两个部署并包含本地基线；完成后不可追加候选。
- 批次可由草稿或完成态进入失效态；失效后终止，历史和候选继续保留。
- 新增 `model:evaluation:manage` 权限，分配给平台管理员和租户管理员；读取继续使用 `model:read`。
- 新增批次查询、创建、候选写入、完成和失效 API，全部使用严格 JSON 和操作审计。
- 系统能力清单新增 `offline_model_evaluation`。

## 数据库边界

- 复合外键保证批次、候选、部署和操作者属于同一租户。
- 触发器核对候选的供应商键、部署键、模型版本、模态、样本数、重复次数和证据类别。
- 数据库拒绝不足两个候选或缺少本地基线的完成操作。
- 批次证据字段不可修改；候选禁止 UPDATE/DELETE；完成态不能退回草稿，失效态不能恢复。
- 数据表不包含冻结集原文、图片、学生身份、模型输出、Secret 或最终成绩。
