# STORY-061C1 离线模型评测证据计划评审（2026-07-30）

## 结论

批准离线评测证据后台，不批准 promotion、外部网络调用、生产路由变化或学生数据外发。

## 产品问题

接入第三方 API 本身不能证明评分效果。EduGrade 必须先回答：同一冻结集上，本地模型和候选部署的教师接受、严重错误、证据、稳定性、时延及成本如何比较；这些数字来自协议 fixture 还是真实授权冻结集。

## 批准范围

- 建立评测批次、候选部署快照、原始计数和派生指标。
- 强制区分 `protocol_fixture` 与 `authorized_frozen_set`。
- 授权冻结集必须记录独立授权引用；fixture 禁止填写授权引用或教师接受计数。
- 一个完成批次至少包含两个候选且必须包含本地基线。
- 完成后的批次和候选不可编辑；证据撤回只能显式失效并保留历史。
- 提供租户隔离的读写 API、独立管理权限和操作审计。

## 明确不做

- 不上传或保存冻结集原文、答题图片、学生身份或最终成绩。
- 不调用真实或 fixture 厂商网络端点。
- 不自动判断模型达标，不内置学科质量阈值。
- 不 promotion、不改变部署状态或租户路由策略。
- 不宣称协议 fixture 代表模型真实效果。
- 本切片不建设前端页面；可见评测中心作为 061C2。

## 验收门槛

- 原始计数边界与派生比例一致。
- 跨租户批次、候选和部署引用失败关闭。
- 候选部署键、供应商键和模型版本由治理库存快照产生，数据库拒绝伪造。
- PostgreSQL 重复执行批次状态机、候选不可变、本地基线和最少候选约束。
- 查看与管理权限分离，所有写操作有审计理由。
- 全量工程门禁通过；真实 PostgreSQL E2E 在 CI 执行。
