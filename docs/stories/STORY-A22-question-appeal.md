# STORY-A22：题目级申诉闭环

状态：Implemented（当前工作树）

## 范围

- 学生针对已发布版本和指定题目提交原因明确的申诉。
- 申诉锚定 `source_release_id`、题目与来源分数；处理不能直接更新分数。

## 接线

- `internal/appeal` 校验学生发布范围和申诉窗口，返回学生安全的状态与公开回复。
- Student Portal 提交并查询题级申诉；需改分时只可关联 Regrade/New Release。
- 学生只能读取自己当前发布版本中的本题答题图，并可用归一化坐标圈选争议区域；不能传入答题卡、切图或存储标识。
- 学校管理员与已分派阅卷教师在成绩管理中查看原图、冻结 Rubric、原评分来源、版本历史和申诉理由；阅卷教师不接触学生身份或内部备注。

## 验证

- Appeal/Score Release 服务与路由测试、OpenAPI/Generated SDK 门禁、学生端类型/构建和管理端类型/生产构建已执行。

## 外部边界

- 申诉原因码、处理时限、通知和学校法务/教务规则需要现场确认。
