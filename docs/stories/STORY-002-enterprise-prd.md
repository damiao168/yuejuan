# STORY-002 企业级 PRD

## 状态

Approved

## 自审审批

审批文件：`docs/stories/STORY-002-approval.md`

## 目标

编写真实企业软件 PRD，保存到 `docs/prd/enterprise-prd.md`。

## 范围

覆盖：

- 产品背景
- 目标客户
- 用户角色
- 核心业务流程
- 题型支持
- AI 使用边界
- 权限与数据范围
- 审计与合规
- 私有化部署要求
- Windows EXE 客户端要求
- 报告与数据分析
- 企业版验收标准
- 非目标范围
- 未来扩展方向

## 非范围

- 不实现代码。
- 不设计数据库细节。
- 不写 API 细节。
- 不实现 UI 页面。

## 验收标准

- 文档可直接交给开发团队。
- 不写营销文案。
- 明确 AI 只能建议，不能绕过人工确认、复核、仲裁和审计。
