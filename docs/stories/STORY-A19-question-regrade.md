# STORY-A19：题目级 Regrade Workflow

状态：Implemented（当前工作树）

## 范围

- 可对已发布版本中的指定题目创建预览、分派并启动重评任务、候选评分与人工审阅。
- 重评差异经审核后进入新的 Score Release；不原地修改历史发布版本。

## 接线

- `internal/regrade` 提供 job 生命周期、任务领取、候选记录和审核接口；候选记录保存本次冻结 Rubric 的采分点与说明。
- 阅卷员通过独立上下文和答题图片接口领取任务，只能获得题目、冻结 Rubric、答案与本次图片；不返回旧分、原阅卷人、来源成绩版本或历史候选信息。
- 学校管理员在成绩管理页分派、批准和启动任务，在候选队列逐项接受、拒绝或标记异常；仅全部处理完成后才可完成复评并生成后继 Score Release 草稿。
- `000096_storyA19_regrade_candidate_evidence.sql` 固化候选 Rubric 采分点和评语，避免只保存一个裸分数。
- A18 Release 与 A20 Gate 负责后续版本发布，不把重评当作直接改分。

## 验证

- Regrade 服务、处理器安全 DTO/盲评上下文、OpenAPI/SDK、服务器定向 Go 测试及管理端生产构建已执行。

## 外部边界

- 大规模重评的任务量、审批责任和向学生解释流程需要学校预生产演练。
