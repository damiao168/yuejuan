# STORY-078：个性化练习

状态：Planned。优先级：P2。依赖：069、071、077；持续交互为未来知识追踪提供数据。

## 问题与范围

把已确认的错因和知识点表现转为可解释的练习清单，同时保护正式考试题池。先做规则推荐和真实作答记录，再评估复杂个性化模型。

- 使用 ItemVersion 的显式用途 exam/practice、公开范围、版权与曝光策略筛选。学生不能继承教师题库 ACL；仅由 practice 发布入口提供允许的题目 DTO，答案/Rubric 依反馈策略分阶段开放。
- 规则推荐结合教师确认知识点、难度标签、最近练习和已做版本，说明选题原因；无合格题目时显示不足，不偷偷调用 LLM 生成未审核题。
- practice_session/attempt 记录学生内部 UUID、item_version、推荐策略版本、开始/提交时间、响应和评分/确认事实；重复提交幂等，不写正式考试 final_grade 或 Score Release。
- 客观题复用规则判分；主观题按适用流程由教师确认建议，未校准 AI 不给正式能力标签。
- 教师可调整、撤销练习清单，学生只访问本人会话；记录真实交互和缺失/退出状态，供未来 BKT/AKT 专项研究审阅。

## 非范围

不在首版训练 Knowledge Tracing、IRT/CAT 或自动生成新题，不使用保密考试题作为公开练习，不把练习分覆盖考试发布，不对一次练习宣称能力变化。

## 预计修改文件

拟新增 `internal/practice/`、用途发布/会话/尝试迁移、学生端练习和教师清单页；修改 questionbank practice eligibility、现有客观题纯判分接口、OpenAPI/SDK。

## 测试方式与验收标准

Go/真实 PostgreSQL 验证用途/版权/权限、版本固定、推荐排除、重复提交、撤销和事实隔离；UI 验证学生只见授权练习与分阶段反馈。真实推荐效果与教师评价在试点单独记录。

验收要求保密题与未知版权题不出学生 DTO，推荐说明引用已确认事实，attempt 重放不重复评分，历史练习固定版本，练习不会改正式成绩；题库退役后既有尝试可追溯但新推荐遵从策略。先验收规则清单，再验收作答与反馈闭环。
