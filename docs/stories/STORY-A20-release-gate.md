# STORY-A20：成绩发布质量门禁

状态：Implemented（当前工作树）

## 范围

- 服务端生成可解释的发布检查表和冻结的门禁证据，不依赖页面按钮状态。
- 未完成阅卷、仲裁、处理异常、身份/页数问题和质量阻断可阻止发布。
- 支持受控豁免申请与决策，保留审计事实。

## 接线

- `internal/releasegate` 提供策略、预览、证据和豁免接口。
- A18 发布动作在锁与当前门禁事实下执行，A13/A19/处理异常提供质量来源。

## 验证

- Release gate 协调、服务、存储及定向 Go 测试已执行。

## 外部边界

- 学校对豁免人的授权、发布时间窗和风险阈值必须在上线前确认。
