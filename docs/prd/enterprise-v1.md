# EduGrade Enterprise v1.0 PRD

## 定位

EduGrade Enterprise 是面向学校、教培机构、考试机构与企业培训部门的智能评测基础设施。系统覆盖试卷采集、OCR、题目结构化、AI 辅助阅卷、人工复核、双评仲裁、成绩发布、申诉处理、学情诊断、考试质量分析、权限审计和私有化部署。

## 非目标

- 不做纯单机 EXE。
- 不做 ChatGPT 套壳式批改。
- 不让 AI 绕过 Rubric 直接决定最终成绩。
- 不把远程监控学生作为早期核心卖点。

## 关键角色

- 平台超级管理员：租户、许可、平台配置。
- 租户管理员：机构配置、模型策略、用户。
- 学校管理员：考试、成绩、审计。
- 学科组长：Rubric、阅卷分配、质量控制。
- 阅卷员：只处理分配题目，默认脱敏。
- 仲裁员：处理双评差异并给最终分。
- 审计员：只读日志和合规报告。

## 核心流程

1. 创建正式考试并选择班级。
2. 上传试卷，结构化题目、分值和答题区域。
3. 配置 Rubric、标准答案、样例库与阅卷策略。
4. 批量采集答卷，进行图像质量检测、版面校准、OCR 和答案切分。
5. 多 Agent 按受控工作流生成建议分、证据、置信度和风险标签。
6. 教师在工作台确认、覆盖或提交复核，所有改分留痕。
7. 双评分差超过阈值时自动进入仲裁。
8. 质量检查通过后审批发布成绩。
9. 学生可查看反馈并提交申诉。
10. 管理者查看学情、题目质量和考试质量分析。

## v1.0 验收

- 能创建正式考试、上传并结构化试卷。
- 能批量采集答卷并完成 OCR、切分与低质量拦截。
- 能配置 Rubric 版本并保留审批记录。
- 能展示 AI 建议分、证据、置信度、风险标签和模型版本。
- 能人工复核、双评仲裁、发布成绩与处理申诉。
- 能生成学生、教师、管理者三类报告。
- 能审计所有关键操作，导出带水印和审批。
- 能以 Docker Compose 运行基础私有化依赖。
