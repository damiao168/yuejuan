# 机构启用与考试工作区操作说明

## 适用人员

本说明用于首次部署后的学校管理员。管理员只需使用 Web 页面即可完成基础机构启用，不需要数据库、Swagger 或命令行操作。

## 首次启用

1. 使用部署负责人提供的机构代码、管理员用户名和首次密码登录。
2. 打开“组织与用户”。系统会根据已存在的真实数据显示当前进度。
3. 填写机构名称和机构代码。机构代码建议使用稳定的英文或数字简称，创建后不要随意变更。
4. 创建当前学年和年级，再创建班级。班级代码在同一学校内应保持唯一。
5. 下载学生导入模板，选择 CSV 后确认字段映射。先检查预览中的重复学号、未知班级和必填字段，再导入有效行；错误行可下载修正后重新导入。
6. 创建至少一个业务用户，选择页面提供的角色并设置强首次密码。密码至少 12 位，需包含大小写字母、数字和符号。管理员不能在此页面创建平台管理员或租户管理员。
7. 创建第一场考试，选择学校、班级、科目、总分和阅卷方式。
8. 页面显示全部步骤完成后，进入考试工作区继续配置试卷。

退出页面或重新登录不会丢失已创建的数据。向导进度来自学校、年级、班级、学生、用户和考试记录，不依赖当前浏览器。

## 使用考试工作区

1. 打开“考试”，在目标考试行点击“工作区”。
2. 顶部核对考试名称、科目、年级、状态、负责人和总体进度。
3. 使用工作区内部导航完成试卷、题目与 Rubric、采集、处理、阅卷、质量、成绩、申诉和报告工作。
4. 工作区地址包含当前考试。刷新页面或复制地址到新窗口后，仍会打开同一场考试。
5. 页面出现黄色提示时，已加载的数据仍可使用；按提示重试或处理缺少的业务信息。整页错误时点击“重试”，不要重复提交正在保存的表单。

## 常见问题

- 看不到某个菜单：菜单按角色与权限显示，请联系机构管理员核对岗位角色。
- 学生导入部分失败：下载错误行，修正学号、姓名或班级代码后重新导入；已成功的行不会因为错误行而丢失。
- 创建用户提示用户名已存在：同一机构内用户名不可重复，请更换用户名。
- 工作区显示“年级待确认”：先确认考试已选择班级，并检查年级、班级数据是否完整，然后刷新工作区。
- 页面提示数据暂时不可用：其他已加载区域仍可操作，可稍后点击顶部刷新按钮重试。
