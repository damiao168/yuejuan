# UI Principles

## 当前阶段

本文件属于项目骨架 Story，只定义 UI 原则。完整 UI 规范将在后续 Story 编写。

## 总体风格

- 专业。
- 克制。
- 高信息密度。
- 强状态反馈。
- 少装饰。
- 重效率。
- 强可解释。
- 适合长时间阅卷。

## Web 管理后台

- 左侧主导航承载考试管理、试卷管理、答卷采集、智能阅卷、人工复核、双评仲裁、成绩管理、学情报告、申诉中心、质量控制、系统管理和审计日志。
- 顶部栏承载租户/学校切换、当前考试、全局搜索、通知、任务队列和用户入口。
- 表格必须支持搜索、筛选、排序、批量操作、导出和审计入口。
- 空状态、错误状态、加载状态必须给出原因和下一步动作。

## 阅卷工作台

```text
顶部：考试 / 题目 / 进度 / 保存状态
左侧：原始答卷查看器
中间：OCR / AI 证据区
右侧：Rubric 与评分面板
底部：同类答案 / 历史样例 / 快捷键提示
```

## 状态表达

- 成功：`#52C41A`
- 警告：`#FAAD14`
- 错误：`#FF4D4F`
- 信息：`#13C2C2`
- 主色：`#1677FF`

## 禁止事项

- 不做营销式首页代替工作台。
- 不做花哨 AI 聊天界面代替阅卷流程。
- 不隐藏低置信度和人工复核风险。
- 不让按钮文案承诺未实现能力。
